To contribute to _lsforce_, please ensure you've installed it in developer mode:
```
bash install.sh 1
```
After making your changes, please **(a)** run `black` and `isort` to conform to the code
style, and **(b)** run `pytest` to ensure all tests pass. 

When submitting a pull request, please provide a clear description of your changes and
reference any relevant issues.
